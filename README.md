# AI 学习打卡

一个手机和电脑都能用的 AI 学习打卡网页：从搜索底层技术、AI 搜索（RAG）到 Agent 与 Harness，按关卡学习、计时打卡、随手记问题。

- `index.html`：应用本体（单文件，无需构建）
- `data.js`：学习路线与资料数据（34 个关卡 + 10 条视频选题）
- `icons.js`：图标
- `assets/`：插画

## 使用

直接打开网页即可。手机浏览器里点「分享 → 添加到主屏幕」，用起来和 App 一样。

学习进度只保存在你自己的浏览器里，不需要注册，也不会上传。换设备时，在「我的」里复制进度码，到新设备粘贴即可同步。

## 数据结构

每个关卡包含：

| 字段 | 应用里 |
|---|---|
| 攻克目标 | 卡片副标题 |
| 第 1 条文字资料、第 1 条视频 | **必读** |
| 其余资料（含公众号链接） | **深挖包**（折叠，建议过关后再看） |
| 工业界案例 | 「工业界怎么做」 |
| 自测思考 | 过关判定题 |

第四模块「PM 必修底座」为概念精讲，正文默认展开。
